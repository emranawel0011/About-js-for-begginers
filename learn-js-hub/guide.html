2. Core JavaScript Concepts You Must Know

A. Variables (Storing Data)

Variables are containers for holding values:

// 1. 'let' - for values that CHANGE over time
let score = 0;
score = score + 10; // score is now 10

// 2. 'const' - for values that STAY THE SAME (Constant)
const websiteName = "My Learn JS Hub";
const maxTries = 3;

B. Functions (Reusable Actions)

A function is a block of code designed to perform a specific task when called:

// Declaring a function
function greetUser(name) {
  return "Hello, " + name + "!";
}

// Calling the function
let greeting = greetUser("Alex"); // Returns "Hello, Alex!"

C. The DOM (Document Object Model)

The DOM is the bridge between JavaScript and HTML. It allows JS to find, read, and change anything on the screen:

// 1. Finding an element by its ID
const heading = document.getElementById("myTitle");

// 2. Changing the text on screen
heading.textContent = "Welcome to JavaScript!";

// 3. Changing styles or classes
heading.style.color = "blue";
heading.classList.add("highlight");

D. Event Listeners (Reacting to Clicks & Typing)

Event listeners tell JavaScript: "Wait until the user does X, then run function Y."

const button = document.getElementById("clickBtn");

// Listen for a mouse click
button.addEventListener("click", () => {
  alert("Button was clicked!");
});

App 1: Live Clock & Stopwatch

The Problem: How do we make a clock tick every second without reloading the page?

The Solution: The setInterval() function and new Date() object:

function updateClock() {
  const now = new Date(); // Gets current time from computer
  const timeString = now.toLocaleTimeString();
  document.getElementById("liveTime").textContent = timeString;

App 3: Live Text & Word Analyzer

The Problem: Count words and characters as the user types in real-time.

The Solution: The 'input' event listener and string.split():

textarea.addEventListener("input", () => {
  const text = textarea.value;

  // Character length
  const totalChars = text.length;

  // Word count: split words wherever there are spaces
  const words = text.trim().split(/\s+/).filter(w => w.length > 0);
  const totalWords = text.trim() === "" ? 0 : words.length;

  // Update numbers on screen
  document.getElementById("charCount").textContent = totalChars;
  document.getElementById("wordCount").textContent = totalWords;
});

App 4: Random Color Generator & Clipboard

The Problem: Generate colors like #3A86FF and let the user copy them with 1 click.

The Solution: Math.random() and navigator.clipboard.writeText():

function getRandomColor() {
  const letters = "0123456789ABCDEF";
  let color = "#";
  for (let i = 0; i < 6; i++) {
    color += letters[Math.floor(Math.random() * 16)];
  }
  return color;
}

async function copyColorCode(colorText) {
  await navigator.clipboard.writeText(colorText);
  alert("Color copied: " + colorText);
}

App 5: Smart To-Do List (CRUD)

The Problem: Add tasks, mark them done, delete them, and remember them when the browser is closed.

The Solution: Arrays of objects and localStorage:

// 1. Task Array
let todos = [
  { id: 1, text: "Learn JavaScript", completed: false }

Bonus Feature: Debounced Search (Filter on Typing Break)

The Problem: Running search on every micro-keystroke can cause jitter or lag. How do we wait until the user pauses typing?

The Solution: The Debounce pattern with setTimeout and clearTimeout:

function debounce(func, delay = 350) {
  let timer;
  return (...args) => {
    clearTimeout(timer); // Cancel previous keystroke timer
    timer = setTimeout(() => {
      func.apply(this, args); // Run search after break!
    }, delay);
  };
}

searchInput.addEventListener("input", debounce(filterCards, 350));

Class Work 3: Palindrome Checker

function isPalindrome(str) {
  const clean = str.toLowerCase().replace(/[^a-z0-9]/g, "");
  return clean === clean.split("").reverse().join("");
}

5. How to Debug JavaScript Like a Pro

Top Developer Secret: Whenever something doesn't work, open your browser's Developer Tools by pressing F12 or Right-Click -> Inspect -> Console.

Use console.log() to see the value of any variable at any point in time:

let score = 45;
console.log("Current score is:", score);

const userList = ["Alice", "Bob", "Charlie"];
console.log("User array contains:", userList);

Common Mistakes to Avoid:

  • Spelling ID names wrong: If your HTML is <button id="submitBtn">, your JS must match exactly: document.getElementById("submitBtn") (Case-sensitive!).
  • Forgetting to prevent default in forms: When a form submits, the browser refreshes. Always use e.preventDefault() to keep your page active!
  • Missing quotes: Strings need quotes ("hello"), variables do not (myVar).
