    Class Work 1

    Reverse a String

    Write a function that takes any string and returns it completely reversed (e.g. "javascript" ➔ "tpircsavaj").

    Output: dlrow olleh
    💡 Solution & Explanation:
    function reverseString(str) {
  // 1. Split string into an array of letters
  // 2. Reverse the array
  // 3. Join the letters back into a string
  return str.split("").reverse().join("");
}
    Class Work 2

    The Classic FizzBuzz Problem

    Print numbers from 1 to N. Multiples of 3 become "Fizz", multiples of 5 become "Buzz", and multiples of both become "FizzBuzz".

    Output:
    💡 Solution & Explanation:
    function fizzBuzz(n) {
  let results = [];
  for (let i = 1; i <= n; i++) {
    if (i % 3 === 0 && i % 5 === 0) results.push("FizzBuzz");
    else if (i % 3 === 0) results.push("Fizz");
    else if (i % 5 === 0) results.push("Buzz");
    else results.push(i);
  }
  return results;
}
    Class Work 3

    Palindrome Checker

    Check if a word is spelled the same backward and forward (e.g. "racecar" or "madam").

    Output: Yes, it's a Palindrome!
    💡 Solution & Explanation:
    function isPalindrome(str) {
  const clean = str.toLowerCase().replace(/[^a-z0-9]/g, "");
  const reversed = clean.split("").reverse().join("");
  return clean === reversed;
}
    Class Work 4

    Find Max & Min Numbers

    Find the highest and lowest numbers in a comma-separated list of numbers.

    Max: 99 | Min: 3
    💡 Solution & Explanation:
    function findMaxMin(arr) {
  // Using Math.max and Math.min with Spread operator (...)
  const max = Math.max(...arr);
  const min = Math.min(...arr);
  return { max, min };
}

    Vowels & Consonants Counter

    Count how many vowels (a, e, i, o, u) and consonants exist in any sentence.

    Vowels: 7 | Consonants: 12
    💡 Solution & Explanation:
    function countVowels(str) {
  const matches = str.match(/[aeiou]/gi);
  return matches ? matches.length : 0;
}
